## DEC-001 — Organização conforme o template

- Data: 2026-10-27.
- Estado: adotada para atender à solicitação de organização e publicação.
- Contexto: aplicação React local, scripts SQL e documentos técnicos; repositório ANG inicialmente vazio.
- Decisão: código em `frontend/`, SQL em `data/database/` e documentação nas subpastas do template do professor, commit `3bdb36e777cc791a0ebb79b2d40ee2a6da127703`.
- Consequência: comandos npm passam a ser executados em `frontend/`. Não foram criados componentes backend/mobile sem implementação. Modelos institucionais e arquivos `-template` foram preservados e identificados como referências.
- Limite: a reorganização não altera regras da aplicação nem implementa integração SQL ou autenticação de produção.

O arquivo `DECISAO-template.md` é o formulário para decisões futuras.
